# 计算原理与适用范围

GridLab 用三个小模型练习电气量、单位与保护曲线。输入电压、电流均为有效值。结果用于教学和概念校验，不能直接作为设备选型、继电保护整定或施工依据。

## 三相功率

本模块适用于**平衡、正弦稳态**三相负载，功率因数为位移功率因数。使用线电压 `U`（V）、线电流 `I`（A）和非负功率因数 `cosφ`（0～1），计算三相总功率：

```text
S = √3 × U × I                          [VA]
P = S × cosφ                           [W]
Q = ±S × √(1 − cos²φ)                   [var]
```

采用被动负载约定：感性负载电流滞后电压，`Q > 0`；容性负载电流超前电压，`Q < 0`。`S` 为视在功率的大小。`kVA`、`kW`、`kvar` 分别为对应基本单位的 1000 倍。该模型未描述谐波畸变和有功反送。

星形连接有 `U线 = √3 U相`、`I线 = I相`；三角形连接有 `U线 = U相`、`I线 = √3 I相`。上面的总功率公式直接使用**线量**，不要把星形的相电压代入后仍乘 `√3`。

默认示例：`U = 400 V`、`I = 100 A`、`cosφ = 0.85`。

| 量 | 感性负载 | 容性负载 |
| --- | ---: | ---: |
| 视在功率 S | 69.282 kVA | 69.282 kVA |
| 有功功率 P | 58.890 kW | 58.890 kW |
| 无功功率 Q | +36.497 kvar | −36.497 kvar |

参考：[Schneider Electric：无功功率定义及三相功率关系](https://www.electrical-installation.org/enwiki/Definition_of_reactive_power)。

## 变压器低压端三相短路

本模块计算变压器低压端**三相金属性短路的对称交流有效值**。以变压器额定三相容量和低压侧额定线电压为标幺基准，假定变压器与上级电源等值阻抗角相同，将阻抗幅值相加：

```text
In = Sn(VA) / (√3 × Un(V))                         [A]
zpu = uk% / 100 + Sn(MVA) / Ssc(MVA)               [标幺值]
Ik = In / zpu                                      [A]
```

`Sn` 是变压器额定三相容量，`Un` 是低压侧额定线电压，`uk%` 是变压器短路阻抗百分数，`Ssc` 是上级电源短路容量。`Sn/Ssc` 中的容量必须同为 MVA。电源短路容量应对应变压器上级连接点，并通过理想变比折算到相同基准；模型未另加电压修正系数。

无限大电源取 `Ssc → ∞`，电源阻抗项为零。有限大电源的短路容量越小，其等值阻抗越大，在其他参数相同时算得的短路电流越小。

默认示例：`Sn = 1000 kVA`、`Un = 400 V`、`uk = 6%`、无限大电源。

```text
In = 1000000 / (√3 × 400) = 1443.376 A
zpu = 6 / 100 = 0.06
Ik = 1443.376 / 0.06 = 24056.261 A ≈ 24.056 kA
```

若同一变压器的上级电源短路容量改为 `100 MVA`，则 `zpu = 0.06 + 1/100 = 0.07`，`Ik ≈ 20.620 kA`。该结果可帮助理解有限大电源的影响。

此模块**不是 IEC 60909 的完整实现，也不是电磁暂态仿真**。它未考虑线路阻抗、电动机反馈、故障电弧、阻抗角差异、设备阻抗容差、直流偏移及短路峰值，不能由此结果直接得到峰值耐受电流。实际网络需按相关标准和设备资料建立完整模型。

参考：[Schneider Electric：低压装置各点的三相短路电流](https://www.electrical-installation.org/enwiki/3-phase_short-circuit_current_(Isc)_at_any_point_within_a_LV_installation)。

## IEC 反时限过电流曲线

以测量电流 `I` 和启动整定电流 `Iset` 定义电流倍数 `M = I/Iset`。当 `M > 1` 时，理想静态动作时间为：

```text
t = TMS × k / (M^α − 1)                [s]
```

`TMS` 是无量纲时间倍率。曲线常数如下：

| 曲线 | 简写 | k | α |
| --- | --- | ---: | ---: |
| 标准反时限 | SI | 0.14 | 0.02 |
| 非常反时限 | VI | 13.5 | 1 |
| 极端反时限 | EI | 80 | 2 |

当 `M ≤ 1` 时，本项目显示“不启动”，不提供有限动作时间。不要把公式用于该区间，也不要将“不启动”读成动作时间为零。固定曲线与 TMS 时，`M > 1` 越大，动作时间越短；固定曲线与 M 时，动作时间与 TMS 成正比。

默认示例：`I = 800 A`、`Iset = 200 A`、`TMS = 0.1`、SI 曲线。

```text
M = 800 / 200 = 4
t = 0.1 × 0.14 / (4^0.02 − 1) ≈ 0.498 s
```

在相同的 `M = 4`、`TMS = 0.1` 下，VI 为 `0.450 s`，EI 为 `0.533 s`。曲线名称描述其反时限形状，不表示 EI 在所有倍数下都比其他曲线快。

测量值和整定值必须采用同一电流基准：都用 CT 一次侧值，或都用二次侧值。例如 CT 为 `800/5 A`，一次测量 `800 A`、一次整定 `200 A`，相应二次值为 `5 A`、`1.25 A`，两侧均有 `M = 4`。不要混用一次测量值与二次整定值。此例假定 CT 理想，未模拟饱和和误差。

界面默认比较曲线均使用**同一电流基准、同一启动值和同一 TMS**。真实保护配合还要考虑各保护所在电压侧、CT 变比和各自整定值，不能仅按曲线图的高低判断选择性。

本模块不包含装置最短动作时间、断路器分闸时间、启动容差、复归过程及厂家规定的有效电流倍数范围。显示时间是理想继电器曲线值，不是完整故障切除时间。

参考：[ABB REJ 527 技术参考手册：IEC 反时限曲线](https://library.e.abb.com/public/ed7bf29f8ef78948c12570eb0045155e/REJ527tech750616ENc.pdf)。
